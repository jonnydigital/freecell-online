**Shipped (U6 a11y slice): expose spoke toolbar Undo/Hint to assistive tech.**
While probing the 07-21 "spoke landscape status-pill parity" backlog item, found
the spokes have **no** aria-hidden landscape pill (Spider/Klondike render
Time/Moves/Game as plain labeled text — already screen-reader accessible), so
that specific item is a **no-op / resolved-by-inspection**. The real parity gap
was elsewhere: FreeCell's shell carries 8 aria-labels but each spoke shell had
only 2 — the **icon-only (or mobile-width icon-only) Undo/Hint buttons** in the
Klondike and Spider desktop toolbars relied on `title=` alone, which is an
unreliable accessible name across screen readers. Added matching `aria-label`s
to those four buttons (`DomKlondikeShell.tsx`, `DomSpiderShell.tsx`).
Layout-neutral, no behavior change, satisfies WCAG Label-in-Name (aria-label
contains the visible/title text). Mobile bottom-bar equivalents already carry
visible text labels and were left untouched.

- Gate: `npx tsc --noEmit` exit 0; `npm run lint` 0 errors / 444 warnings
  (baseline). Diff = 4 insertions / 2 deletions, exactly the four aria-labels.
