## Phase 4 — Improvement shipped (1)
**a11y: expose FreeCell desktop toolbar buttons to assistive tech.** `SubBarBtn` (used by all 8 icon-only controls — Undo, Redo, Hint, Mute, Ghost Mode, Bookmark, Statistics, Settings) rendered `title=` only with no `aria-label`, so its accessible name came from `title` alone — unreliable across screen readers. This is exactly the weakness the 07-25 run fixed on the Klondike/Spider desktop toolbars; that commit's note assumed FreeCell was "already aria-labelled," but it was not — FreeCell used title-only. Added `aria-label={title}` (derived from the already-localized `title` string) to `SubBarBtn`, closing the parity gap in the correct direction. Layout-neutral, no behavior change. `npx tsc --noEmit` clean; `eslint` 0 errors (445 pre-existing warnings). Verified live post-deploy.
