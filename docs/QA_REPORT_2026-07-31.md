## Phase 4 — Improvement shipped (1)
**a11y: label the FreeCell portrait mobile top-bar timer and move counter** (`DomGameShell.tsx`, commit `e0e4def`). The portrait mobile top bar (`!isLandscapeMobile` branch, ~line 1705) renders only the raw values — the timer (`0:00`) and an abbreviated move count (`0 movs.`) — dropping the "Time"/"Moves" text labels the desktop sub-bar shows to save horizontal space. For a screen-reader user the timer therefore announced as bare digits with no context, and the move count used the abbreviated `movesShort` form. Added localized `aria-label` to both spans: `` `${copy.time}: ${timerDisplay}` `` and `` `${moveCount} ${copy.moves}` ``. `copy.time` / `copy.moves` are already defined across all six locales (Time/Tiempo/Temps/Zeit/Tempo/Tempo) and consumed by the desktop bar, so the labels are localized and type-safe. Layout-neutral (aria-label does not affect rendering), no behavior change, no live region so no announcement spam.
