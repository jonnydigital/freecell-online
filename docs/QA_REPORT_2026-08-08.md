### Mobile (375 / 390 / 414) — **BLOCKED this run (infrastructure), reported**
True-viewport mobile could not be executed:
- The Chrome extension's `resize_window` reported success but the host window
  never dropped below desktop width (`innerWidth` stayed 1440, `outerWidth` 0),
  so it renders the desktop layout — unusable for mobile breakpoint QA.
- The documented CDP harness (`npm run qa:mobile`) needs a native-arch Chrome to
  spawn; this arm64 sandbox has none. `@puppeteer/browsers` only serves an
  x86-64 `chrome-headless-shell` (fails to exec on aarch64); Playwright's native
  arm64 chromium download (~170 MB) exceeds the per-tool-call time cap. No root
  (sudo blocked by no-new-privileges) so apt install of chromium is unavailable.
