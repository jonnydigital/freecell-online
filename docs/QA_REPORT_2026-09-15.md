### Root cause of the duplicate WebSite (network-wide, homepage scope)
`src/app/(main)/layout.tsx` already emits the canonical site-wide `WebSite` node
(`id="ld-website-site"`, with `publisher` Organization + `SearchAction`). Every
homepage rendered via `src/app/(main)/page.tsx` **also** emits its own `WebSite`:
- spokes (Klondike/Spider/FreeCell): `id="ld-website"` from `webSiteJsonLd`
  (SearchAction, but no publisher — a strict subset of the layout node);
- hub: `id="ld-website-hub"` from `hubWebSiteJsonLd`.

Because the page renders inside the layout, **both** WebSite nodes appear on every
domain's homepage → duplicate `WebSite` entity. Interior pages (e.g. `/tripeaks`)
correctly show a single WebSite (layout only) — confirmed.
