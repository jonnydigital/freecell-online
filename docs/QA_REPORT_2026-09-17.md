## Blocker resolution (was DAY 3)

- **Root of the block:** `xcode-select -p` points at `/Applications/Xcode.app/...`,
  whose license was never accepted, so every `/usr/bin/git` call (an `xcrun` shim)
  died with the Xcode-license error. The sandbox git path is separately unusable
  (no push credentials + undeletable `.git/*.lock` on the mounted volume).
- **Fix (no sudo, no system change, no owner action):** invoke the standalone
  Command Line Tools git directly via `DEVELOPER_DIR=/Library/Developer/CommandLineTools`.
  Verified `git version 2.50.1 (Apple Git-155)`; full status / fetch / pull / commit /
  push all work. This is the path used for every git op this run.
- The stale `.git/index.lock` left by the blocked sandbox runs was removed host-side.
- `sudo xcodebuild -license accept` (the previously-reported owner fix) is **no longer
  required**, though accepting it would also restore the plain `/usr/bin/git` path.

## Phase 4 — Improvement SHIPPED: dedupe homepage WebSite JSON-LD

**Bug confirmed still live before the fix.** Counted JSON-LD `WebSite` entities on the
live homepages this run: **2** on playfreecellonline.com, **2** on solitairestack.com
(hub), **2** on playklondikeonline.com — should be 1 each.

**Root cause (re-verified in source):** `src/app/(main)/layout.tsx` emits the canonical
site-wide WebSite node (`id="ld-website-site"`, with `publisher` Organization +
`SearchAction`). `src/app/(main)/page.tsx` **also** emitted its own WebSite on every
homepage — the `webSiteJsonLd` const via three spoke `<script id="ld-website">` tags, and
the `hubWebSiteJsonLd` const via the hub `<script id="ld-website-hub">` tag. Because the
page renders inside the layout, both appeared on every homepage; interior pages were
already single (Phase 3).

**Fix:** removed the redundant `webSiteJsonLd` + `hubWebSiteJsonLd` consts and their four
`<script>` emissions from `src/app/(main)/page.tsx`, keeping the single canonical WebSite
in `layout.tsx`. No behavior / layout / route / type / locale change; Game / WebApplication
/ ItemList / FAQPage / Organization nodes untouched. Diff **+2 / −23**, one file.

**Validation (in-sandbox, on the applied change):**
- `npx tsc --noEmit` → **exit 0**.
- `npm run lint` → **0 errors, 368 warnings** — identical to the 09-14 baseline; no new
  warnings.

Commit `6d7c110 fix(seo): remove duplicate WebSite JSON-LD from homepages`.
