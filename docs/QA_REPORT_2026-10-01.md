## Tooling note
- Mac-host Xcode `git` (`/usr/bin/git`) is blocked by an unaccepted Xcode license (CLT updated Sep 3). Worked around by invoking the CLT git binary directly (`/Library/Developer/CommandLineTools/usr/bin/git`), which bypasses the xcrun license shim and retains Mac keychain creds for push. device_bash git commits work but can't unlink `.git` locks (no delete perm in the mount) — locks cleaned via osascript rm. **Recommend `sudo xcodebuild -license accept` on the host to restore the plain `/usr/bin/git` path.**
