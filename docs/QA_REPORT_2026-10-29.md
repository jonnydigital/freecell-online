## Phase 4 — Improvements

### (1) Code — lint-polish slice (dead adapter param), 280 → 278 warnings
`src/app/(main)/golf/GolfGamePage.tsx`: removed the dead `to: any` parameter from the
`isLegalMove` adapter (was `(engine, from, to)` → `(engine, from)`). Golf legality depends
only on the source cascade (cards move to waste only); `to` was never read (line 39 is a
comment, not a usage; whole-word grep confirmed declaration-only). The sibling
`executeMove` already underscores its unused `_to`. The adapter interface in
createGamePage.tsx declares `isLegalMove: (engine, from, to) => boolean`; a 2-param
function is structurally assignable to that 3-param type, and the caller
(`adapter.isLegalMove(engine, from, to)` @84) passes the 3rd arg which is simply ignored —
so **type-safe and behavior-inert**. Removing the param cleared exactly two warnings on
line 38 (`no-unused-vars` on `to` + `no-explicit-any` on its `: any`): 280 → 278, 0 errors,
0 new warnings. tsc --noEmit exit0 before+after, jest 72/72 (7 suites). No behavior/layout/
route/type/locale change. Continues the 10-05..10-28 dead-code cadence.
